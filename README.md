# Winter Arc

Dein Winter Arc als kleine Web-App: Start und Dauer festlegen (30, 60, 90 Tage oder bis Silvester),
dein „Warum“ aufschreiben, Gewohnheiten täglich abhaken, perfekte Tage sammeln und jeden Tag des Arcs im Überblick sehen.

- Eine einzige Datei (`index.html`), keine Anmeldung, keine Server – die Daten bleiben auf dem Gerät (localStorage).
- Sicherung als JSON in den Einstellungen.
- Auf dem iPhone: in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Schriften: Manrope und Cormorant Garamond (SIL Open Font License, siehe `fonts/`).
